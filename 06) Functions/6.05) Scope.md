This is another concept we've been simplifying until now.

Scope is important when working with functions because it determines where variables can be accessed. When we create a function, we create a new scope, and variables declared inside that function can only be accessed within that scope. For example:

``` GDScript
extends Node

func _ready():
	var greeting = "Hello!"
	print(greeting)
```

The `print()` function can use the variable `greeting` because it's inside the same scope. However, this changes when we try to use that same variable outside its scope:

``` GDScript
extends Node

func _ready():
	var greeting = "Hello!"

func greet():
	print(greeting)
```

This code will give an error saying that there's no such thing as `greeting` in the current scope, and it's true, because `greeting` just exists inside the `_ready()` function.

When we need to use a value in another function, we have different options. We could move the variable to a scope that both functions can access, or we could pass the value to the function as a parameter.

The first option would be to declare the variable outside the functions. This creates a global variable, which means that the variable can be accessed from any part of the script:

``` GDScript
extends Node

var greeting = "Hello!" # Global variable

func _ready():
	print(greeting) # The variable "greeting" is within the scope

func greet():
	print(greeting) # The variable "greeting" is within the scope
```

The second option would be to pass the value to the function as a parameter:

``` GDScript
extends Node

func _ready():
	var greeting = "Hello!"
	greet(greeting)

func greet(greeting: String):
	print(greeting)
```

Usually, we want to have as few global variables as possible because having a lot of them can make our code harder to read and understand. That's why knowing how to apply the concept of scope is important.
