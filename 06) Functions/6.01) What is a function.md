If you've been paying attention to the code examples, maybe you've noticed that most of them use this code structure:

``` GDScript
extends Node

# Variables

func _ready():
	# Code here
```

Well, even though it's not the time to explain what `extends Node` means, the time has come for the `func _ready()` and the reason behind declaring the variables outside of it.

That is a function, they're used to separate the code in logical containers that we can name, use and reuse whenever we want and as many times as we want. They're also often used to separate different responsibilities, making our code easier to organize and understand.
