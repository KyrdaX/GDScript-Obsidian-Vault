To declare a function, we use the keyword `func` followed by the function name, like this:

``` GDScript
extends Node

func my_function():
	print("This is my very own function!")
```

Now, we have a new function in our code, but you'll see that if you execute this script, it won't do anything, this is because all we did was declare the function, but functions must be called to execute the code they contain, for that, we write their name followed by parentheses `()`:

``` GDScript
extends Node

func _ready():
	my_function()

func my_function():
	print("This is my very own function!")
```

In the function `_ready()`, which the Godot Engine executes automatically at the start (we'll get into that further) we are calling `my_function()`, we are calling the function. This means that the code inside `my_function()` will be executed.
