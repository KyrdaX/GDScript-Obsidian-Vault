Typing functions works slightly differently than typing variables. When we type a function, we are not actually assigning a type to the function itself. Instead, we are specifying the type of value that the function returns.

Let's say that we want our function to return a text greeting our player. We could just declare the function and use `return` normally, but GDScript wouldn't know what type of value the function returns. We mostly want to specify the return type so that GDScript can warn us about possible problems that we might not otherwise detect.

To type the output of a function, we use an arrow (`->`) right after the parentheses of its declaration, followed by the type of the output:

``` GDScript
extends Node

func _ready():
	var greeting = get_greeting("Hello", "CoolName")
	print(greeting)

func get_greeting(greeting, name) -> String:
	var full_greeting = greeting + ", " + name
	return full_greeting
```

In this example, the function `get_greeting()` is returning a `String` composed of the way the player wants to be greeted and the player name.

If the function does not return a value, we can make GDScript know that by using the keyword `void`:

``` GDScript
extends Node

func _ready():
	print_hello()

func print_hello() -> void:
	print("Hello")
```

We can see how `print_hello()` does not return a value, so we let GDScript know this.
