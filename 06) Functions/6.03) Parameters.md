Parameters are really useful when we want to give a function a value we want it to work with.

For example, let's say our player has a name, and we want to have a function to greet our player. We can give the player's name to the function through a parameter. Parameters are specified between the parentheses of a function declaration:

``` GDScript
extends Node

var player_name = "ReallyCoolName"

func _ready():
	greet_player(player_name)
	greet_player("AnotherCoolName")

func greet_player(name):
	print("Hello, " + name)
```

We can see how we used the same function but with a different parameter each time we call it, and that we can use the value of variables as parameters as well. The output would be:

``` text
Hello, ReallyCoolName
Hello, AnotherCoolName
```

Functions can have as many parameters as you want, for example, we could choose how the player wants to be greeted:

``` GDScript
extends Node

func _ready():
	greet_player("Hello", "AwesomeName")
	greet_player("Howdy", "CoolName")

func greet_player(greeting, name):
	print(greeting + " " + name)
```

Now we can specify how a player wants to be greeted, and the function can take it as a parameter along with the player's name.

We can specify the type that a certain parameter expects the same way we do with variables:

``` GDScript
extends Node

func _ready():
	greet_player("Hello", "AwesomeName")
	greet_player("Howdy", "CoolName")

func greet_player(greeting: String, name: String):
	print(greeting + " " + name)
```

This is the exact same code, but now, our function knows that both parameters must be of type `String`.

It's important to know that functions can take different types of parameters as well. For example, you could give a function the player's name and their current level, allowing you to print the name followed by the level they're at in the game.
