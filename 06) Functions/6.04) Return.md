The keyword `return` allows a function to give back a value, for example:

``` GDScript
extends Node

var multiplied_number

func _ready():
	multiplied_number = multiply_by_two(2)
	print(multiplied_number)

func multiply_by_two(number):
	var result = number * 2
	return result
```

In this example, we have a function that multiplies whatever number you give it through a parameter by two, and then returns the result. For clarity, we are using variables, but we could do the same thing without them, just like this:

``` GDScript
extends Node

func _ready():
	print(multiply_by_two(2))

func multiply_by_two(number):
	return number * 2
```

This version is a bit less verbose and saves us two variables. The actual impact of this change is not something we need to worry about for now, so feel free to use variables until you are ready to write it this way.
