Referencing a variable is simple, its name is the identifier, knowing that, referencing it would be as simple as:

``` gdscript
extends Node

func _ready():
	var my_variable = "Hello!"
	print(my_variable)
```

Because we are using the variable `my_variable` as an identifier of the value `Hello!`, we can use it to print the actual value, don't get confused by this:

``` gdscript
extends Node

func _ready():
	var my_variable = "Hello!"
	print("my_variable")
```

In this example, we are not referencing the variable, we are directly printing a value. We reference variables by using their name without any quotes.
