Collections are complex ways to store data in an organized way.

<h1>1) Lists</h1>
Lists can store multiple values, accessed by their position in the list:

``` gdscript
extends Node

func _ready():
	var my_list = ["Hello!", "Wassup", "How's it going?"]
```

In this example we have three different greetings, if we wanted to print, for example, the second one (`Wassup`), we would have to access its position inside the list:

``` gdscript
extends Node

func _ready():
	var my_list = ["Hello!", "Wassup", "How's it going?"]
	print(my_list[1])
```

To access a certain position inside the list, we reference the list variable followed by `[]` with the position number inside. In programming, positions are usually started at 0, that's why `my_list[1]` references the second value of the list.


<h1>2) Dictionaries</h1>
Dictionaries are pairs of a key and a value, each value accessed by its key:

``` gdscript
extends Node

func _ready():
	var my_dict = {
		name = "Jhon",
		surname = "Jhonson",
		age = 26,
		fav_color = "Blue",
		married = true,
		has_children = false
	}
	
	print(my_dict.name)
	print(my_dict.surname)
	print(my_dict.married)
```

As shown in the example above, dictionaries are commonly used to store properties of something in particular, like a person (name, surname...).
