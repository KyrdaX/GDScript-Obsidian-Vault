Lists, or as we'll call them from now on, `Arrays`, can store multiple values, accessed by their position:

``` gdscript
extends Node

var my_list = ["Hello!", "Wassup", "How's it going?"]
```

In this example we have three different greetings, if we wanted to print, for example, the second one (`Wassup`), we would have to access its position inside the list:

``` gdscript
extends Node

var my_list = ["Hello!", "Wassup", "How's it going?"]

func _ready():
	print(my_list[1])
```

To access a certain position inside the list, we reference the list variable followed by `[]` with the position number inside. In programming, positions are usually started at 0, that's why `my_list[1]` references the second value of the list.

When we want to check if a certain item is part of the list, we can use the `in` operator:

``` GDScript
extends Node

var my_list = ["Item1", "Item2", "Item3"]

func _ready():
	print("Item2" in my_list)
```

It would print either true or false if the item is or isn't part of the list, respectively.
