Dictionaries are pairs of a key and a value, each value accessed by its key:

``` gdscript
extends Node

func _ready():
	var my_dict = {
		name = "Jhon",
		surname = "Jhonson",
		age = 26,
		fav_color = "Blue",
		married = true,
		has_children = false
	}
	
	print(my_dict.name)
	print(my_dict.surname)
	print(my_dict.married)
```

As shown in the example above, dictionaries are commonly used to store properties of something in particular, like a person (name, surname...).

In programming, when we want to access something that's inside any other thing, we use a dot, for example, the script above prints the property `name`, `surname` and `married` of a dictionary, accessed by a dot followed by their keys.
