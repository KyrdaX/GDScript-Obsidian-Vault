Floats can represent numbers with decimals, they can also represent whole-number values, such as `10.0`. They're commonly used for a lot of things like positions, speed, health percentages, etc:

``` gdscript
extends Node

var my_float = 10.5
```

Something to consider is that, if we had any number followed by `.0`, it would turn into a float:

``` GDScript
extends Node

var my_float = 10.0
```

This example shows it perfectly, as long as the number has a decimal part, whether it adds to the number or not, it'll be consider a float.
