They're used to do the usual mathematical operations, the most common ones are these:

| Operator |    Meaning     |
| :------: | :------------: |
|   `+`    |    Addition    |
|   `-`    |  Substraction  |
|   `*`    | Multiplication |
|   `/`    |    Division    |
|   `%`    |    Modulus     |
It's not important to know every single operator, the modulus is not used much.

An example of this applied to actual code:

``` gdscript
extends Node

func _ready():
	print(2 + 2)
	print(3 - 1)
	print(5 * 2)
	print(6 / 3)
	print(6 % 2)
```
