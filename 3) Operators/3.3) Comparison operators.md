These are used to compare values, they return a boolean (true / false)

| Operator |        Meaning        |
| :------: | :-------------------: |
|   `==`   |       Equal to        |
|   `!=`   |     Not equal to      |
|   `>`    |     Greater than      |
|   `<`    |       Less than       |
|   `>=`   | Greater than or equal |
|   `<=`   |  Less than or equal   |

These could not make sense right now, but they're useful once you learn about conditionals.

``` GDScript
extends Node

func _ready():
	print(2 > 3) # It would print "false" because 2 is not greater than 3
	print(3 == 3) # True, because 3 is equal to 3
	# ...
```
