Logic operators are used to combine certain boolean operatios to create more complex ones.

| Operator |              Meaning              |
| :------: | :-------------------------------: |
|  `and`   |         Both must be true         |
|   `or`   | At least one of them must be true |
|  `not`   |       Inverts the condition       |

This could be applied to code this way:

``` GDScript
extends Node

func _ready():
	print(true and true) # True
	print(true and false) # False
	
	print(true or false) # True
	print(false or false) # False
	
	print(not false) # True
	print(not true) # False
```
