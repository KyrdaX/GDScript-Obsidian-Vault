Logic operators are used to combine certain boolean operations to create more complex ones.

| Operator |              Meaning              |
| :------: | :-------------------------------: |
|  `and`   |         Both must be true         |
|   `or`   | At least one of them must be true |
|  `not`   |       Inverts the condition       |

This could be applied to code this way:

``` GDScript
extends Node

func _ready():
	print(true and true) # True
	print(true and false) # False
	
	print(true or false) # True
	print(false or false) # False
	
	print(not false) # True
	print(not true) # False
```

This is all syntax, but we could have a more realistic example:

``` GDScript
extends Node

var is_alive: bool = true
var strength: float = 10.0

func _ready():
	print(is_alive and strength > 0)
```

This would print true if we are alive and our strenght is greater than 0.
