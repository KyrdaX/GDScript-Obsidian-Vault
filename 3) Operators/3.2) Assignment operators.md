These operators are used to assign or modify values of variables, here are the most used ones:

| Operator |          Meaning          |
| :------: | :-----------------------: |
|   `=`    |        Assignment         |
|   `+=`   |    Addition assignment    |
|   `-=`   |  Substraction assignment  |
|   `*=`   | Multiplication assignment |
|   `/=`   |    Divison assignment     |
We would apply this concept like this:

``` gdscript
extends Node

func _ready():
	var health = 100
	
	health -= 20 # health equals 80
	health += 10 # health equals 90
	health /= 2 # health equals 45
	health *= 2 # health equals 90
```

This code substracts 20 from the player's health, then adds 10, takes half of it and multiplies it by 2, it all gets assigned to the variable, so if we were to add prints for every instruction, we would see that the variable changes its value with every single one of them.
