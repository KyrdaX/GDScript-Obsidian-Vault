They're used to do the usual mathematical operations, the most common ones are these:

| Operator |    Meaning     |
| :------: | :------------: |
|   `+`    |    Addition    |
|   `-`    |  Subtraction   |
|   `*`    | Multiplication |
|   `/`    |    Division    |
|   `%`    |    Modulus     |
They're pretty self explanatory, the modulus gives us the remainder after a division.

An example of this applied to actual code:

``` gdscript
extends Node

func _ready():
	print(2 + 2) # 4
	print(3 - 1) # 2
	print(5 * 2) # 10
	print(6 / 3) # 2
	print(6 % 2) # 0
```
