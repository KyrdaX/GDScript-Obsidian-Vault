To assign a value, we use the `=` symbol, which means assignment:

``` gdscript
extends Node

var my_variable = "Hello!"
```

This code declares a variable called `my_variable` and assigns the text `Hello!` to it. We can reassign the value of a variable like this:

``` GDScript
extends Node

var my_variable = "Hello!"

func _ready():
	my_variable = "Goodnight!"
```
