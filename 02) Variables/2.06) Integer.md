Integers, commonly called `int`, is the type we use when we want to store a non-decimal number:

``` gdscript
extends Node

var my_int = 10
```

In this example, we can see that the variable `my_int` stores the number `10`, something important to consider is that this is a number because it's not enclosed by quotes, if it were, it wouldn't be an integer, it would be a String:

``` GDScript
extends Node

func _ready():
	print("10") # This prints a String
	print(10) # This prints an Integer
```

We can store and reference an integer in the same way we did with a String. Since it is a number, we can also use it in mathematical operations as we'll see in further notes:

``` gdscript
extends Node

var my_int = 10

func _ready():
	print(my_int)
```
