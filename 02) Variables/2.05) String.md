In programming, a string is a sequence of characters used to represent text. Strings are written between quotes, just like this:

``` GDScript
extends Node

var my_string = "This is a text!"

func _ready():
	print(my_string)
```

The variable called `my_string` stores a text, that means its type is String.

When we work with strings, you'll often come across a term called `concatenation`, this means, essentially, adding Strings together.

We do that in Godot by using the `+` sign between the strings we want to add:

``` GDScript
extends Node

var my_concatenation = "Hello " + "World!"

func _ready():
	print(my_concatenation)
```

Of course, we can concatenate inside the print function as well:

``` GDScript
extends Node

func _ready():
	print("Hello" + " " + "World!")
```

In this example, we concatenate the string `Hello` with a space (`" "`) and then the string `World!`.

As well as concatenating raw values with the ones stored in variables, for example, greeting a player:

``` GDScript
extends Node

var player_name = "VeryCoolName"

func _ready():
	print("Hello, " + player_name)
```

We have to be careful when concatenating, because String can't be combined with other types like int directly, or we'll get an error. To fix that, we cast the value to String using `str()`:

``` GDScript
extends Node

var score = 10

func _ready():
	print("You died... Got " + str(score) + " points.")
```
