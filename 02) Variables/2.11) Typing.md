Typing in GDScript is a good practice because it makes the code more explicit, helps catch errors earlier, and can improve performance in some cases.

There are many different types in GDScript, but for now, these are the type names for the values we already know:

|     Type     | Description |
| :----------: | :---------: |
|   `String`   |   String    |
|    `int`     |   Integer   |
|   `float`    |    Float    |
|    `bool`    |   Boolean   |
|   `Array`    |    Array    |
| `Dictionary` | Dictionary  |

We can type variables by adding a colon after the variable name, followed by the type name:

``` GDScript
extends Node

var my_text: String = "This is an example text."
var my_int: int = 10
var my_float: float = 5.0
```

This tells GDScript that my_text must contain a String value.

If we initialize the variable when we declare it, we can use `:=` to let GDScript set its type automatically:

``` GDScript
extends Node

var my_text := "This is an example text."
```

In this case, GDScript knows that `my_text` is a `String`, so we don't have to specify the type ourselves.
