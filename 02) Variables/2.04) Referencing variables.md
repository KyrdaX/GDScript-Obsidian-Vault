We can reference a variable by using its name:

``` GDScript
extends Node

var my_variable = "Hello!"

func _ready():
	print(my_variable)
```

Because `my_variable` refers to the value stored in the variable, we can use it to print the actual value, don't get confused by this:

``` GDScript
extends Node

var my_variable = "Hello!"

func _ready():
	print("my_variable")
```

In this example, we are not referencing the variable, we are directly printing a value. We reference variables by using their name without any quotes.
