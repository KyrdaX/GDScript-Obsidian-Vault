Boolean values, usually known as bool, just represent if something is true or false. They're commonly used when something can have two possible states: true or false. We'll see how useful they are when we learn about conditionals:

``` gdscript
extends Node

func _ready():
	var my_boolean_1 = true
	var my_boolean_2 = false
```

In this example, we have two variables, `my_boolean_1` and `my_boolean_2`, each one has its own value (true and false respectively).
