When we want to check if the value of a certain thing is equal to a specific value, with the tools we have, we could do it like this:

``` GDScript
extends Node

var player_name = "VeryCoolName"

func _ready():
	if player_name == "VeryCoolName":
		print("Your name is very cool!")
	elif player_name == "NotVeryCoolName":
		print("Your name is not very cool...")
	else:
		print("Your name is mid.")
```

This is valid, but we are checking the value of the same variable over and over again, for this, we usually use the match statement. It lets you take the value of something and explicitly check if it equals to different things:

``` GDScript
extends Node

var player_name = "VeryCoolName"

func _ready():
	match player_name:
		"VeryCoolName":
			print("Your name is very cool!")
		"NotVeryCoolName":
			print("Your name is not very cool...")
		_:
			print("Your name is mid.")
```

The `_` symbol in match is, basically, the same as the `else` keyword in if statements, if the value we are checking is not equal to any of the previous options, it executes the code inside.

Also, the match syntax supports that various options can execute the same block of code, just like this:

``` GDScript
extends Node

var player_name = "AlsoCoolName"

func _ready():
	match player_name:
		"VeryCoolName", "AlsoCoolName":
			print("Your name is very cool!")
		_:
			print("Your name is not very cool...")
```
