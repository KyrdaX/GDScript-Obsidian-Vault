Conditionals add another layer to your code, with this tool, now your code can follow different paths depending on different conditions, using what we already learned from the previous lessons.

| Keyword |                                             Meaning                                              |
| :-----: | :----------------------------------------------------------------------------------------------: |
|  `if`   |                        Executes a block of code if the condition is true                         |
| `elif`  | Allows you to chain various conditions, they execute in order and stop when any condition is met |
| `else`  |      If none of the previous conditions have been met, then this block of code will execute      |

A conditional block starts with an if and can contain one or more elif statements and an optional else statement.

This is a use example:

``` GDScript
extends Node

func _ready():
	# Conditional block nº1
	if true:
		print("It's true!")
	else:
		print("It's not true...")
	
	# Conditional block nº2
	if true and true:
		print("Both are true!")
	elif true and false:
		print("Just the first one is true")
	elif false and true:
		print("Just the second one is true")
	else:
		print("None are true")
```

Once a condition is met, the rest of the conditional block is skipped.
