We call an instance of a class an object. This means that we have created something concrete from the class that we can actually use.

To instantiate a class in GDScript, the language itself provides the `.new()` method, which automatically creates an object from a class.

Let's say we want to create an instance of the `Car` class that we defined in [7.01) What is a class](7.01\)%20What%20is%20a%20class). We can do it using the `.new()` method that I mentioned earlier:

``` GDScript
extends Node

func _ready()
	var car1 = Car.new()
	var car2 = Car.new()
```
