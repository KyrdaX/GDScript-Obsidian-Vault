A class is an abstraction of something we want to represent. Let me explain.

If you want to create a car for your game, you could create a class named `Car`. Then, you can define certain variables or functions.

Variables, when they belong to a class, are called properties, meaning that we could define properties for the car's speed or the number of people that can get in the car.

Functions also have another name when they belong to a class: methods. You could define methods for making the car accelerate or making it take damage when it collides.

To create a class, you just have to make GDScript know that the script you are editing belongs to a class by adding the keyword `class_name` to the script:

``` GDScript
class_name Car
extends Node

var speed := 0.0 # property called speed
var size := 4 # property called size

func accelerate(acceleration: float) -> void: # method called accelerate
	speed += acceleration
	print("Current speed: " + str(speed))

func take_damage() -> void: # method called take_damage()
	print("The car has collided!")
```
