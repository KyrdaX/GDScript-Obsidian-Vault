Constructors are important when we want our class to do something whenever it is created. For example, let's say that when our car is created, we want to print that a car has been created, along with its speed and size. To do that, we use a special method called `_init()`:

``` GDScript
class_name Car
extends Node

var speed := 0.0
var size := 4

func _init():
	print("A car has been created! Speed: " + str(speed) + " Size: " + str(size))

func accelerate(acceleration: float) -> void:
	speed += acceleration
	print("Current speed: " + str(speed))

func take_damage() -> void:
	print("The car has collided!")
```

With our class declared like this, the `_init()` method will print the message whenever we create an object from this class.
