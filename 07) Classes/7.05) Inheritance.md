Inheritance is a really complex yet important concept to know about. It also finally allows us to explain the other magical line we always use in our examples: `extends Node`.

Inheritance allows us to create a class based on another class, inheriting its properties and methods without having to define them again. This means that we can create a very generalized class and then create other classes that inherit from it and add their own properties and methods.

To inherit from another class, we normally use the keyword `extends`, followed by the name of the class we want to inherit from.

We can also use the keyword `super`, which allows us to call methods from the parent class.

Here's an example:

``` GDScript
class_name TwoSeater
extends Car

func _init():
	super() # This would call the _init() method of the class Car
	print("It's a two-seater!")
```

We can redefine how certain methods behave if we declare them again in the inherited class:

``` GDScript
class_name TwoSeater
extends Car

func take_damage():
	print("The two-seater took damage...")
```

Even though we inherited the `take_damage()` method from the `Car` class, we defined it again, changing its behavior when called on an object created from the `TwoSeater` class.
