As we saw in [[7.01) What is a class]], a class can contain custom properties and methods, here, we'll explore their potential using, once again, the `Car` class as an example.

When we create objects from a class, the object automatically has all properties and methods defined in it. That means that we can access the properties, modify them or call the methods:

``` GDScript
extends Node

func _ready():
	var car1 = Car.new()
	var car2 = Car.new()
	
	print(car1.size)
	print(car2.speed)
	
	car1.speed = 30.0
	car2.size = 2
	
	car1.take_damage()
	car2.accelerate(20.0)
```

Something that's really important to know is that, even if two objects are created from the same class, modifying a property or calling a method on one object will only affect that object itself, not the other instances.
