As the name implies, this loop keeps running a block of code until a certain condition is met:

``` GDScript
extends Node

var counter = 0

func _ready():
	while counter < 5:
		print(counter)
		counter += 1
```

In this case, we are printing the numbers from 0 to 4 with just a few lines of code, this saves us from having to repeat a bunch of instructions over and over again.

These types of loops have a dangerous twist, they can become infinite if we don't set a condition that will always be met. For example:

``` GDScript
extends Node

var counter = 0

func _ready():
	while counter < 5:
		print(counter)
```

Now we have the same block of code, but without incrementing the counter. That means the counter will always be at 0 and, therefore, the exit condition (`counter < 5`) will never be met.

If this happens during execution, the program will likely crash, since we are forcing it to repeat something forever, exhausting it.
