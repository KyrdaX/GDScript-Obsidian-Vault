For loops are used when you know the exact amount of times you want to repeat a block of code. For example, we want to print `Hello` five times:

```GDScript
extends Node

func _ready():
	for n in 5:
		print("Hello!")
```

In this example, `n` represents the current iteration of the loop. The loop will run five times, and `n` will have a different value on each iteration.

We can print `n` to see what happens:

```GDScript
extends Node

func _ready():
	for n in 5:
		print(n)
```

This will print:

```text
0
1
2
3
4
```

Notice that the loop starts counting from `0`, so when we tell it to repeat five times, the values of `n` go from `0` to `4`.

This is useful when we want to do something a specific number of times while also keeping track of which iteration we are currently on.

If we want to iterate over a range of values, for instance, let's say we want to go from 10 to 20, we can use `range()` to specify the starting value and the ending value:

``` GDScript
extends Node

func _ready():
	for n in range(10, 20):
		print(n)
```

This code would just print the numbers from 10 to 19, because the ending value is exclusive.

For loops are also commonly used to iterate over arrays, for example:

``` GDScript
extends Node

var inventory: Array = ["Stick", "Sword", "Pickaxe"]

func _ready():
	for item in inventory:
		print(item)
```

In this example, `items` represents the current item in the array. The loop will go through each item one by one and print it.

The output would be:

``` text
Stick
Sword
Pickaxe
```
