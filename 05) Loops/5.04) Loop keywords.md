In loops, we have two interesting keywords that could be useful when working with them, depending on what we wanna do.

<h1>1) Break</h1>
Break is used to exit the loop immediately, for example:

``` GDScript
extends Node

func _ready():
	for n in 5:
		if n == 3:
			break
		
		print(n)
```

In this example, the loop starts normally, but when `n` is `3`, it enters the `if` statement and breaks the loop. This means that the rest of the code in that iteration is not executed, and the loop stops iterating completely.

The result would be:

``` text
0
1
2
```

This also works with while loops:

``` GDScript
extends Node

var counter = 0

func _ready():
	while counter < 5:
		if counter == 3:
			break
		
		print(counter)
		counter += 1
```

<h1>2) Continue</h1>
Continue is used to skip the rest of the iteration without completely stopping the loop, for example:

``` GDScript
extends Node

func _ready():
	for n in 5:
		if n == 3:
			continue
		
		print(n)
```

In this example, the loop would iterate normally but when `n` equals `3`, it will skip the rest of that iteration, so the result would be:

``` text
0
1
2
4
```

Again, we can also use this keyword in while loops:

``` GDScript
extends Node

var counter = 0

func _ready():
	while counter < 5:
		if counter == 3:
			counter += 1
			continue
		
		print(counter)
		counter += 1
```

We increment the counter inside the if statement to allow the loop to continue, otherwise, the counter would always be equal to 3, and it would become an infinite loop since the exit condition cannot be met.
